FHIR RESTful Capabilities

Mode: server

Toda interacción usa TLS 1.2 o superior. Los datos personales nunca viajan en la URL: la consulta por RUN se hace con POST [base]/EpisodeOfCare/_search.

Security
Enable CORS: no
Security services supported: OAuth

OAuth 2.0 con grant_type=client_credentials. Cada client_id se asocia a uno o más códigos DEIS; el receptor rechaza un MessageHeader.sender que no corresponda al cliente autenticado.

Summary of System-wide Operations
ConformanceOperationDocumentation
SHALL$process-message

Recibe un BundleNotificacionGES y responde, de forma síncrona, un BundleRespuestaGES (ok, transient-error o fatal-error). Idempotencia por identifier[folio] del recurso foco; reintento de transporte con el mismo Bundle.identifier.
