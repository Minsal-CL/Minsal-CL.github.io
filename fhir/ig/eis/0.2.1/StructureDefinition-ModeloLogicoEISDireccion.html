ModeloLogicoEISDireccion 0..* Base Modelo Logico para el tipo de dato Direccion
Instances of this type can be the target of a Reference
ModeloLogicoEISDireccion.region Σ This element is included in summaries. 0..1 Coding Es la máxima unidad administrativa en que se divide el país. La regionalización que actualmente rige en el país, comenzó a aplicarse en 1974. Actualmente existen 16 regiones
ModeloLogicoEISDireccion.provincia Σ This element is included in summaries. 0..1 Coding Es una subdivisión administrativa menor que la región y que puede abarcar varias comunas
ModeloLogicoEISDireccion.comuna Σ This element is included in summaries. 1..1 Coding Es una subdivisión administrativa menor que la región que corresponde a una zona urbana, rural o mixta
ModeloLogicoEISDireccion.limiteUrbanoCensalREVISAR Σ This element is included in summaries. 0..1 Coding Indica si la dirección se encuentra dentro del área urbana o rural, según la clasificación oficial del Instituto Nacional de Estadísticas (INE) de Chile.
ModeloLogicoEISDireccion.tipoDeVia Σ This element is included in summaries. 0..1 Coding Corresponde al tipo o clasificación de calle. Puede utilizarse para datos de ubicación tanto de prestadores individuales, institucionales como usuarios del sistema de salud.
ModeloLogicoEISDireccion.datoDeLaVia Σ This element is included in summaries. 2..* Element Corresponde al nombre de la calle, avenida, pasaje, etc. Puede utilizarse para datos de ubicación tanto de prestadores individuales, institucionales como usuarios del sistema de salud.
Constraints: ele-1

ModeloLogicoEISDireccion.datoDeLaVia.numero Σ This element is included in summaries. 1..1 string Corresponde al número de la dirección. Puede utilizarse para datos de ubicación tanto de prestadores individuales, institucionales como usuarios del sistema de salud.
ModeloLogicoEISDireccion.coordenadasGeograficas Σ This element is included in summaries. 0..1 Element Corresponde a las coordenadas geográficas de la dirección, expresadas en formato de latitud y longitud. Puede utilizarse para datos de ubicación tanto de prestadores individuales, institucionales como usuarios del sistema de salud.
